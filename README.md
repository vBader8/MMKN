# منصة IFCE — شهادة أساسيات التأمين (الإصدار 4)

منصة مذاكرة تفاعلية عربية (RTL) مبنية على النص الدراسي الرسمي «امتحان شهادة أساسيات التأمين IFCE — الإصدار 4 (2025–2026)».

**إعداد وتطوير: بدر خالد — تيليجرام [@B1Ver](https://t.me/B1Ver)**

## المحتوى
- **11 فصلاً**: دروس منظمة بنفس ترتيب أقسام الكتاب (1A، 1B…) مع تنبيهات «انتبه» للنقاط التي يكثر السؤال عنها.
- **خريطة ذهنية تفاعلية** لكل فصل + خريطة شاملة للمنهج + جداول مقارنة للمفاهيم المتشابهة + جدول «الأرقام والمدد».
- **بطاقات المصطلحات** (Flashcards) لكل فصل.
- **598 سؤالاً**: أسئلة الامتحان الذاتي (معاد صياغتها بنفس الإجابات المعتمدة في مفتاح الكتاب) + أسئلة «بين السطور» المتوقعة.
- بعد كل اختيار يظهر **شرح مبسط للإجابة الصحيحة** أياً كانت إجابتك.
- **اختبار محاكي**: 100 سؤال / ساعتان بنفس توزيع المنهج الرسمي (18/10/36/12/2/22).
- **مراجعة أخطائي** (تكرار متباعد)، **خطة مذاكرة ذكية** مبنية على نتيجتك السابقة، **بحث** شامل، **وضع داكن**، أزرار رجوع/تقدم.
- **الاقتراحات والملاحظات** تُرسل إلى تيليجرام @B1Ver.

## حفظ التقدم والمزامنة
- يُحفظ التقدم تلقائياً في المتصفح (localStorage).
- **رمز المزامنة** في صفحة «حسابي» لنقل/دمج التقدم بين الأجهزة دون أي إعداد.
- **تسجيل الدخول عبر Google** (اختياري): املأ `js/config.js` بإعدادات مشروع Firebase وفعّل Google Sign-in وFirestore، والصق قواعد `firestore.rules`، وأضف نطاق موقعك في Authorized domains.

## التشغيل والنشر
موقع ثابت بالكامل (HTML/CSS/JS بدون أي بناء):
- محلياً: `python3 -m http.server` ثم افتح `http://localhost:8000`.
- **Vercel**: استورد المستودع كمشروع جديد (Framework: Other، بدون أمر بناء) — سيُعطيك رابطاً مباشراً قابلاً للمشاركة.
- يعمل على Chrome وSafari وEdge وFirefox والجوال.

## تنبيه
المنصة تعليمية مستقلة؛ الملخصات والأسئلة بصياغة تعليمية مبنية على الكتاب ولا تعيد نشر نصه، ولا تغني عن الرجوع إليه.
