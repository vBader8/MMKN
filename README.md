# منصة IFCE — شهادة أساسيات التأمين (الإصدار 4)

منصة مذاكرة تفاعلية عربية (RTL) مبنية على النص الدراسي الرسمي «امتحان شهادة أساسيات التأمين IFCE — الإصدار 4 (2025–2026)».

**إعداد وتطوير: بدر خالد — تيليجرام [@B1Ver](https://t.me/B1Ver)**

🔗 **الموقع المباشر: https://vbader8.github.io/MMKN/** (ينشر تلقائياً عبر GitHub Pages مع كل دفعة للمستودع)

## المحتوى
- **11 فصلاً**: دروس منظمة بنفس ترتيب أقسام الكتاب (1A، 1B…) مع تنبيهات «انتبه» للنقاط التي يكثر السؤال عنها.
- **خريطة ذهنية تفاعلية** لكل فصل + خريطة شاملة للمنهج + جداول مقارنة للمفاهيم المتشابهة + جدول «الأرقام والمدد».
- **بطاقات المصطلحات** (Flashcards) لكل فصل.
- **598 سؤالاً**: أسئلة الامتحان الذاتي (معاد صياغتها بنفس الإجابات المعتمدة في مفتاح الكتاب) + أسئلة «بين السطور» المتوقعة.
- بعد كل اختيار يظهر **شرح مبسط للإجابة الصحيحة** أياً كانت إجابتك.
- **اختبار محاكي**: 100 سؤال / ساعتان بنفس توزيع المنهج الرسمي (18/10/36/12/2/22).
- **مراجعة أخطائي** (تكرار متباعد)، **خطة مذاكرة ذكية** مبنية على نتيجتك السابقة، **بحث** شامل، **وضع داكن**، أزرار رجوع/تقدم.
- **الاقتراحات والملاحظات** تُرسل إلى تيليجرام @B1Ver.

## حفظ التقدم والمزامنة (Supabase)
قاعدة البيانات: مشروع Supabase باسم `ifce-study` (الإعدادات في `js/config.js`).
- **مفتاح المزامنة الشخصي**: يعمل فوراً بدون تسجيل؛ أنشئ مفتاحاً في صفحة «حسابي» وأدخله في الجهاز الآخر فيتزامن التقدم تلقائياً.
- **الدخول برمز على البريد** و**الدخول عبر Google**: يحفظان التقدم في جدول `progress` المحمي بـ RLS (كل مستخدم يرى بياناته فقط).
  - Google يتطلب مرة واحدة: Supabase ← Authentication ← Providers ← Google (Client ID و Secret من Google Cloud)، ثم URL Configuration: ضع رابط موقعك في Site URL و Redirect URLs.
  - رمز البريد يعمل مع خدمة البريد المدمجة في Supabase بحدود إرسال منخفضة؛ للاستخدام العام أضف SMTP خاصاً من Authentication ← Emails.
- **الاقتراحات** تُحفظ في جدول `feedback` وتُنسخ لإرسالها على تيليجرام @B1Ver.
- **رمز النقل اليدوي**: نسخ/لصق يعمل حتى بدون إنترنت.

## التشغيل والنشر
موقع ثابت بالكامل (HTML/CSS/JS بدون أي بناء):
- محلياً: `python3 -m http.server` ثم افتح `http://localhost:8000`.
- **Cloudflare Pages (موصى به)**: Workers & Pages ← Create ← Pages ← Connect to Git ← مستودع MMKN، الفرع `claude/zen-davinci-pva65g`، Framework preset: None، Build command: `sh build.sh`، Build output directory: `public`. ستحصل على رابط `ifce-study.pages.dev` ويتحدث تلقائياً مع كل دفعة للمستودع.
- **Cloudflare عبر سطر الأوامر**: `sh build.sh && npx wrangler deploy` (بعد `npx wrangler login`).
- بعد النشر أضف الرابط في Supabase ← Authentication ← URL Configuration (Site URL و Redirect URLs) ليعمل تسجيل الدخول.
- **Vercel**: استورد المستودع كمشروع جديد (Framework: Other، بدون أمر بناء).
- يعمل على Chrome وSafari وEdge وFirefox والجوال.
